# Cuaderno Competencial

Herramienta de evaluación competencial por criterios para Lengua Castellana y Literatura de 2.º de ESO (Decreto 107/2022, Comunitat Valenciana).

Abrir la herramienta: https://sanforbel.github.io/cuaderno-competencial/

Registra el nivel alcanzado criterio a criterio, calcula a la vez la calificación competencial y la del acuerdo de departamento, muestra la cobertura de la evaluación y genera el plan de recuperación de cada alumno.

Los datos del alumnado se guardan solo en el navegador del docente y se identifican con iniciales o código.
